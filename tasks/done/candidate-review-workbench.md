# candidate-review-workbench — 可视化候选用例审核工作台

状态：DONE

创建日期：2026-07-30

## 目标

让用户无需直接阅读整段运行 JSON，即可统一审核 OpenAPI 基础草稿和 AI 候选用例，
逐条选择、编辑请求与预期状态码，并安全地替换或追加到测试编辑器。

## 范围

- 展示基础生成器和 AI 助手产生的候选用例及来源。
- 支持逐条选择、全选、取消全选。
- 支持编辑名称、HTTP 方法、相对路径、查询参数、JSON 请求体和预期状态码。
- 支持将选中候选替换测试编辑器，或在目标地址一致时追加。
- 展示 AI 候选类别与生成理由。
- 保留高级 JSON 编辑入口和最终人工运行确认。
- 补充前端契约测试、文档和回归验证。

## 非范围

- 在浏览器执行测试或绕过 `/api/v1/runs`。
- 编辑认证请求头、依赖、提取规则或运行变量。
- 自动接受、自动运行或自动持久化 AI 候选。
- 本任务内读取真实 API Key或验证真实付费模型质量。
- 修改已有后端公开 API。

## 验收标准

- [x] OpenAPI 与 AI 生成成功后，候选自动进入统一审核工作台。
- [x] 用户可逐条选择并编辑安全字段，错误 JSON 会被明确阻止。
- [x] 替换操作使用候选来源的目标地址和选中用例，不自动执行。
- [x] 追加操作仅在目标地址一致且用例 ID 不冲突时成功。
- [x] 工作台不提供请求头、密钥、依赖或提取规则编辑入口。
- [x] 所有动态文本使用安全 DOM API，不执行模型或文档提供的 HTML。
- [x] 全量测试、分支覆盖率、JavaScript 语法和工作区检查通过。

## 风险与假设

- 单次运行只有一个 `base_url`，因此不同目标的候选不能直接混合追加。
- 编辑器仍保留高级 JSON，最终后端 Pydantic 模型与目标访问策略是权威安全边界。
- AI 候选是不可信草稿，前端校验用于用户体验，不能替代后端校验。
